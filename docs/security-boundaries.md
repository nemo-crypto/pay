## 升级与运行边界

- 环境标识为 `demo`，或 `live:stripe_<test|live>:onramp_<sandbox|production>` 的组合；准确格式由 `Config.EnvironmentKey()` 生成，例如 `live:stripe_test:onramp_sandbox`。即使某通道尚未启用，数据库仍绑定这组环境设置。
- 新空库自动绑定；同环境重启可继续使用。不同环境使用不同 `DATABASE_PATH`，不能通过改环境标记把测试余额转为正式余额。
- 已有业务数据但没有 `payment_environment` 的旧库拒绝自动接管。先备份、确认历史支付环境并审核迁移；本次不修改现有本地数据库，也不提供跳过检查的开关。纯演示可改用一个新文件，保留原文件。已有正式系统上线前必须先完成受控数据迁移。
- demo 的 JWT 自定义密钥不再生效，旧自定义密钥签发的 demo token 需重新获取；正式配置使用独立随机密钥。演示密钥公开是本地 mock 设计，不能用于正式认证。
- 若更换正式商户账号但环境类型未变，本次标记不能自动识别商户归属变化，仍须使用独立数据库或审核迁移。多实例、分布式限流及真实供应商协议验收仍按既有部署说明处理。
